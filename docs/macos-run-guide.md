# Bubli macOS 실행 안내

## 실행 파일

- `Bubli-macOS-0.1.0-arm64.dmg`
- Apple Silicon Mac(M1/M2/M3/M4)용 빌드입니다.

## 실행 방법

1. `Bubli-macOS-0.1.0-arm64.dmg`를 엽니다.
2. `Bubli.app`을 `Applications` 폴더로 옮깁니다.
3. `Applications`에서 `Bubli.app`을 실행합니다.
4. 제공된 테스트 계정으로 로그인합니다.

## 보안 경고가 뜨는 경우

이 앱은 프로젝트 제출용 빌드라 Apple 공증이 적용되어 있지 않을 수 있습니다.

1. `Bubli.app`을 우클릭 또는 Control-클릭합니다.
2. `열기`를 선택합니다.
3. 보안 안내 창에서 다시 `열기`를 선택합니다.

그래도 실행되지 않으면 `시스템 설정 > 개인정보 보호 및 보안`에서 Bubli 실행을 허용한 뒤 다시 실행합니다.
