# Bubli macOS 제출용 실행 안내

작성일: 2026-07-06

이 문서는 프로젝트 산출물로 제출하는 Bubli macOS 앱의 실행 안내입니다. 현재 macOS 앱은 무료 Apple 계정 기준의 release 빌드이며, Apple Developer ID 공증(notarization)이 적용된 정식 외부 배포 빌드는 아닙니다. 따라서 심사자 Mac에서 최초 실행 시 macOS Gatekeeper 보안 안내가 표시될 수 있습니다.

## 제출 파일 구성

필수로 함께 전달할 파일은 다음입니다.

1. `Bubli-macOS-0.1.0-arm64.dmg`
   - macOS 앱 설치/실행용 DMG 파일입니다.
   - 공개 다운로드 위치: `public/downloads/macos/Bubli-macOS-0.1.0-arm64.dmg`
   - 원본 빌드 산출물 위치: `src-tauri/target/release/bundle/dmg/Bubli_0.1.0_aarch64.dmg`
   - Apple Silicon Mac 전용 빌드입니다. M1/M2/M3/M4 Mac에서 실행할 수 있습니다.

2. `macos-submission-run-guide-2026-07-06.md` 또는 같은 내용의 PDF
   - 심사자가 최초 실행 차단 상황을 해결할 수 있도록 이 안내문을 함께 제출합니다.

3. 제출용 README
   - 프로젝트 실행 URL, 테스트 계정 안내, 주요 기능 설명, 백엔드/API 서버 상태를 적습니다.
   - 테스트 계정 비밀번호나 민감한 환경 변수는 공개 저장소에 커밋하지 말고 제출 폼/별도 문서/학교 지정 방식으로 전달합니다.

권장으로 함께 전달할 파일은 다음입니다.

1. 소스 코드 압축 파일 또는 Git 저장소 링크
   - 프론트엔드, Tauri 앱, 백엔드 저장소가 분리되어 있다면 각각의 링크와 실행 방법을 명시합니다.

2. 웹 앱 URL
   - macOS 보안 정책이나 기기 아키텍처 문제로 앱 실행이 어려울 때 확인할 수 있는 백업 경로입니다.
   - 현재 앱이 바라보는 서비스 URL: `https://bubli.n-e.kr`

3. QA 결과 요약
   - macOS 앱 실행, 로그인 세션 유지, 주요 화면 렌더링, DMG 무결성 검증 결과를 간단히 첨부합니다.

## 실행 환경

- macOS: Apple Silicon Mac 권장
- 아키텍처: `arm64`
- 네트워크: 필요
- API 서버: `https://bubli.n-e.kr`
- 웹소켓: `wss://bubli.n-e.kr/ws`

Intel Mac에서는 현재 DMG가 실행되지 않을 수 있습니다. Intel Mac 지원이 필요하면 별도의 `x86_64` 또는 universal macOS 빌드가 필요합니다.

## 기본 실행 방법

1. 제출된 `Bubli-macOS-0.1.0-arm64.dmg` 파일을 다운로드합니다.
2. DMG 파일을 더블클릭해서 엽니다.
3. `Bubli.app`을 `Applications` 폴더로 드래그합니다.
4. `Applications` 폴더에서 `Bubli.app`을 실행합니다.
5. 로그인 화면이 표시되면 제공된 테스트 계정으로 로그인합니다.

## macOS 보안 안내가 표시되는 경우

무료 Apple 계정으로 만든 제출용 빌드는 Apple Developer ID 공증이 적용되어 있지 않으므로, 최초 실행 시 macOS가 앱 실행을 막을 수 있습니다. 이 경우 아래 방법 중 하나로 실행합니다.

### 방법 1. 우클릭으로 열기

1. `Applications` 폴더에서 `Bubli.app`을 찾습니다.
2. 앱을 더블클릭하지 말고, 우클릭 또는 Control-클릭합니다.
3. 메뉴에서 `열기`를 선택합니다.
4. 보안 경고 창이 뜨면 다시 `열기`를 선택합니다.

일반적으로 이 방법을 한 번 수행하면 이후부터는 더블클릭으로 실행할 수 있습니다.

### 방법 2. 개인정보 보호 및 보안에서 허용

1. `Bubli.app` 실행이 차단되었다는 메시지를 확인합니다.
2. macOS `시스템 설정`을 엽니다.
3. `개인정보 보호 및 보안`으로 이동합니다.
4. 하단 보안 섹션에서 `Bubli` 실행 차단 안내를 찾습니다.
5. `그래도 열기` 또는 `허용`을 선택합니다.
6. 다시 `Bubli.app`을 실행합니다.

### 방법 3. 터미널로 quarantine 속성 제거

심사 환경에서 터미널 사용이 허용되는 경우에만 사용합니다.

```bash
xattr -dr com.apple.quarantine /Applications/Bubli.app
open /Applications/Bubli.app
```

DMG 안에서 바로 실행하지 않고 `Applications` 폴더로 옮긴 뒤 실행하는 것을 권장합니다.

## 정상 실행 확인 기준

앱이 정상 실행되면 다음을 확인할 수 있습니다.

1. `Bubli` 앱 창이 열립니다.
2. 로그인 후 대시보드 또는 프로젝트 화면으로 진입합니다.
3. 우측 상단에 사용자 프로필 정보가 표시됩니다.
4. 캘린더, 채팅, 리소스, 설정 등 주요 메뉴로 이동할 수 있습니다.

## 알려진 제한사항

1. 이 제출용 DMG는 Apple Developer ID 공증 빌드가 아니므로 최초 실행 시 Gatekeeper 안내가 표시될 수 있습니다.
2. 현재 DMG는 `arm64` 전용입니다. Intel Mac에서 실행하려면 별도 빌드가 필요합니다.
3. 앱 사용에는 인터넷 연결과 운영 중인 API 서버가 필요합니다.
4. 테스트 계정 정보는 앱에 포함되어 있지 않으며, 제출 안내에 별도로 제공해야 합니다.
